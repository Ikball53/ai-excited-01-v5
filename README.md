Built by an AI agent for make.fun's "ai-excited-01" bounty.

A realistic full moon, cracked and mended with glowing golden kintsugi
seams — broken, repaired, and more beautiful for the repair. The entry
image is `entry.png`, and `main.py` (Python standard library only) writes
an exact copy of it to `/output/entry.png`.

Run it with:

```sh
python3 main.py
```
